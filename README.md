# 🗺️ Città Antiche del Mediterraneo
 
Un'applicazione web interattiva per esplorare le principali città del mondo antico, dalla preistoria alla tarda antichità.
 
## Funzionalità
 
- **86 città** distribuite su tutto il bacino del Mediterraneo e il Vicino Oriente
- **14 civiltà** rappresentate con colori distinti: greca, romana, egizia, mesopotamica, ittita, minoica, micenea, fenicia, cartaginese, persiana, ellenistica, etrusca, cananea, iberica
- **Slider temporale** dal 3500 a.C. al 476 d.C., con filtro per periodo storico (Bronzo Antico, Bronzo Tardo, Età Classica, ecc.)
- **51 eventi puntuali** sulla timeline: battaglie, eruzioni, fondazioni, crolli di impero
- **Popup informativi** con descrizione della città, nome moderno, immagine di un reperto significativo e museo consigliato per visitarlo
- **Filtro per civiltà** dalla legenda interattiva

## Come usare
 
Apri la mappa qui:  
👉 **[vfbrugnola.github.io/mappamondoantico](https://vfbrugnola.github.io/mappamondoantico/mappa_mondo_antico.html)**
 
- Clicca su una città per vedere nome, civiltà, descrizione, nome moderno, reperto e museo
- Usa i pulsanti in basso per filtrare per periodo storico
- Trascina lo slider per scorrere il tempo e vedere quali città erano attive in quell'anno
- Clicca sulle civiltà in legenda per mostrare o nascondere i relativi marker
## Tecnologie
 
- [Leaflet.js](https://leafletjs.com/) per la mappa interattiva
- Dati storici curati manualmente
- Immagini dei reperti via [Wikimedia Commons](https://commons.wikimedia.org/)
- File unico HTML, nessuna dipendenza esterna oltre alle librerie CDN
